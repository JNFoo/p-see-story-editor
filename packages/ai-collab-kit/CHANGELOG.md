# ai-collab-kit changelog

What changed in each version, newest first, in plain words. Each entry says what is new or how much better it got, with numbers where there are numbers. Figures not measured say "about" or "not measured".

## 2026-10-14
**New:** a "Cost habits" section and an "ask first" list in the `AGENTS.md` template. The cost habits tell the AI to spend compute and waiting time on purpose and to report the real elapsed time and approximate compute at the end of each request, so the cost of a request is known. The ask-first list names the actions the AI must check with the person before taking.

**Tested in:** no browser; this is writing, not code. Not run or measured.

## 2026-10-12
**New:** a written process for a person and an AI assistant building software together, taken from how the Story Editor was built. About 2,430 words in the guide (ten habits, testing and speed recipes, pitfalls, a new-project checklist) and three templates of about 700 words together: an `AGENTS.md`, a task board that several sessions can share, and a first message for a fresh AI session. It is not code.

**Tested in:** no browser; this is writing, not code. Not run or measured.
