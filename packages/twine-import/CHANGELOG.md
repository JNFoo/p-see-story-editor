# twine-import changelog

What changed in each version, newest first, in plain words.

## 1.0.0 · 2026-10-17
First version. It used to be part of story-format; it moved out so that people who only want the story data model do not carry it. It reads Twine 2 pages and archives, Twee 3 and Twine 1, turns SugarCube and Harlowe code into rules where it can, and says in plain words what it could not carry over. The `twine-to-story` command came with it.
